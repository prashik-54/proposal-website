For You, Vanshu ❤️ | A Digital Love Letter
A deeply personal, interactive web experience built as a tribute to a love story that began in Nagpur in January 2026. This project serves as a digital scrapbook and a lifetime promise, designed specifically for Vanshu.

📖 The Story
This website narrates the journey of Prashik and Vanshu. It captures the essence of their first meeting at Nagpur’s Dikshabhumi, the courage it took to ask for an Instagram handle, and the growth of a connection that turned into a beautiful promise on January 30, 2026.

✨ Features
Interactive Timeline: A visual journey through key milestones, from the first dance to the official proposal.

Digital Polaroid Gallery: High-fidelity photo frames with glassmorphism effects, floating hearts, and "handwritten" captions.

The Promise Vault: A dedicated section for life-long vows, categorizing commitment through good days, hard days, and everything in between.

The Ring Symbolism: A deep dive into the meaning of "The Arms," "The Circle," and "The Silver," explaining the responsibility behind the gift.

Immersive Atmosphere:

Global Background: Pinkish-transparent hearts drifting across all pages.

Continuous Music: A persistent, glassmorphic audio player that keeps the mood set during navigation.

The Final Acceptance: An emotional finale where the user can officially "lock in" the promise with a celebration of hearts and confetti.

🛠️ Tech Stack
Frontend: React.js

Animations: Framer Motion

Icons: Lucide React

Styling: Tailwind CSS

Components: Radix UI / Shadcn UI

Routing: React Router DOM
